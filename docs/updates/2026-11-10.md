# Targeted Addition — 2026-11-10

## Scope and method

This is a targeted addition, not a literature sweep: the last full check remains 2026-09-28. The survey's benchmark evaluates three methods that the registry did not list. Each was read in its original source and its artifacts were checked on 2026-11-10 against the arXiv pages, the official GitHub repositories, and the official Hugging Face model and dataset cards (repository metadata and file listings).

## New core records in `registry/papers.yaml`

| First release | Record | Native signal and boundary |
|---|---|---|
| 2026-07-08 | [VLAC-Cut (HELP)](https://arxiv.org/abs/2607.09776) | A rollout segmentation critic. It estimates signed task progress that can decrease and fall below the starting state, explains each change, and predicts cut points between progress-making, idle, failure-inducing, and recovery segments. Listed as a hybrid verifier: progress, success/failure analysis, and segmentation are separate outputs. The authors describe the score as closer to a policy-conditioned value than to a policy-agnostic reward. |
| 2026-07-10 | [Robo-ValueRL](https://arxiv.org/abs/2607.09866) | A separate, history-conditioned value estimator over three camera views. Its target is normalized remaining time with a penalty on failed trajectories, learned as a distribution over bins. Listed under temporal value. Value differences are thresholded into the action-quality indicator that conditions the policy, so the value reflects the trajectories it was fitted on. |
| 2026-10-15 | [Flora-Rewarder](https://arxiv.org/abs/2610.31779) | One fine-tuned VLM with three prompt types: an episode outcome score from 1 to 5, a dense action-quality score per 0.5 s step, and rubric step scores. Listed as a hybrid verifier because the three are separate judgments; the episode score alone is an outcome signal. Release date is the Hugging Face model card's; the arXiv report followed on 2026-10-22. |

## Not added

- **Video Progress Benchmark (VPB)** from the HELP paper is the held-out split of VLAC-Cut's own annotation corpus. It is a model-native test, and its split, label source, and baseline protocol have not been audited for `registry/benchmarks.yaml`.
- **Flora-Captioner** and **Flora-TempSeg**, the other two models of the FLORA suite, label and segment data; neither returns a task-conditioned judgment of robot behavior.
- The quality-conditioned policy and the online residual adapter of Robo-ValueRL are policies; only the value estimator is recorded.

## Unresolved items

- Robo-ValueRL's code repository and dataset card state no license; the MIT tag covers the model card only.
- The "other" license of the VLAC-Cut model and dataset cards was not resolved to specific terms.
- No training data release was found for Flora-Rewarder, and its weights are limited to non-commercial research use.
