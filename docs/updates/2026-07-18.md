## Existing entry updated

DenseReward is confirmed as arXiv:2607.13033, submitted 2026-07-14. Its official project page describes a 27k-episode synthesized dataset and release intent, but this audit did not verify usable official code, weights, or data links; those fields remain unresolved.

Robo-Dopamine and Robometer were also re-audited at the training-data level:

- Robo-Dopamine's gated 35M-sample GRM dataset and released checkpoints are now linked. Its signed `regress` supervision is primarily created by reversing the order of sampled states inside expert trajectories; this must not be described as a 35M-sample natural-failure corpus.
- Robometer's RBM-1M composition, dual progress/preference objectives, model weights, and processed-data repository are now recorded. The processed Hugging Face repository exists, but the official project page still marks the canonical RBM-1M release as coming soon, and the aggregate data inherits upstream terms.

## Reward-model training-data expansion

Six egocentric or paired human–robot datasets were added as cross-cutting supervision resources rather than core reward models:

- HRDexDB: paired human/robot dexterous grasps with real robot success/failure, object pose, and tactile signals;
- IndEgo: industrial ego/exo video with keysteps, mistake labels/summaries, gaze, and hand pose;
- EgoPER: frame-level procedural error annotations, including slip and correction events;
- CaptainCook4D: controlled normal versus induced-error executions;
- HoloAssist: action correctness plus instructor intervention purpose and timing;
- Assembly101: natural order variation, propagated mistakes, and corrections across synchronized ego/exo views.

The registry now records failure provenance and candidate reward targets. The recommended supervision split is: calibrated progress from successful/expert robot data; trajectory preference and success from mixed-expertise/failed robot rollouts; semantic error/correction auxiliaries from human ego data; and cross-embodiment alignment from paired human–robot observations. Human video is not treated as a source of robot action labels.

Data caveats:

- EgoPER's public repository exposes data and annotations, but a reusable license was not found.
- Assembly101 and HRDexDB are non-commercial datasets according to their current data cards/licenses.
- IndEgo's multi-terabyte Mistake Detection tree is still actively receiving files and annotations; reproducible use requires pinning a revision.
- IndustReal in the handover image is a broad industrial/procedural-error bucket, not a sufficiently identified single dataset, so it was not entered as one record.

- RFM-HRI: valuable HRI failure/reaction data, but it does not evaluate task-conditioned manipulation behavior in the project’s sense.
- FARL: a failure-aware offline-to-online RL paradigm, without a separately characterized reward/evaluator model.
- Recover, Discover, Plan: retained only as adjacent failure-recovery/planning context because its central contribution is skill/concept learning, not reward-model evaluation.

## Coupled value-prediction expansion

Following a second scope review on 2026-07-18, the registry adds a cross-cutting `model_coupling` axis for systems that predict value/progress together with a robot policy or world model. This is not a new reward-semantics family: each entry retains an outcome, progress, preference, temporal-value, or verifier meaning.

New records:

- ACE-Brain-0.5: shared embodied backbone with progress estimation for execution monitoring and recovery;
- Cosmos Policy: joint action, future-state, and expected rewards-to-go generation;
- PALM: joint action and within-subtask progress prediction;
- RISE: compositional dynamics and progress-value models for imagined policy improvement;
- ProgVLA: policy-internal remaining-horizon critics and near-completion prediction;
- NavWAM: joint future-view, goal-progress, and action prediction for navigation;
- MV-WAM: joint visual/action/value generation with progress-based deviation detection and rollback.

Existing VLAC, ViVa, and Robot Self-Improvement via Human-Video Dynamics Models are cross-indexed under the same architectural axis. The registry now distinguishes `policy_internal`, `joint_world_action_value`, `compositional_world_value`, `shared_backbone_multi_interface`, and `value_world_model` coupling patterns, plus whether the value is externally queryable at inference or only used internally during training/control.

Artifact caveats:

- Cosmos Policy has Apache-2.0 code and an official Hugging Face collection containing models and training datasets; licenses remain item-specific and the collection is currently marked archived.
- ACE-Brain-0.5 has an official model checkpoint, but runnable task code and reusable license terms were not verified from the project repository/model card.
- PALM has code and repository-linked checkpoints, but no repository license was verified.
- RISE releases code under Apache-2.0 and a pretrained dynamics checkpoint; it states that released data/checkpoints use CC BY-NC-SA 4.0. A complete value/policy checkpoint bundle was not verified.
- ProgVLA promises code, checkpoints, and its real-world dataset upon publication; these are not yet counted as available.
- No usable official code or checkpoint link was verified for MV-WAM or NavWAM during this audit.

## World-model / VLA reward-loop follow-up

A targeted follow-up separates three frequently conflated designs:

- World-VLA-Loop jointly predicts future video and binary reward inside the diffusion world model. That native reward drives imagined VLA RL, and failure rollouts from the improved policy are fed back to update the world model.
- World-Env keeps the video simulator and reward model separate. Its instant reflector freezes a LLaVA backbone and trains a scalar head for per-frame task-completion probability, which supplies both VLA reward and early termination.
- RoboAlign-R1 is the Qwen-VL-linked case: it fine-tunes Qwen3-VL-8B-Thinking as a six-dimensional teacher judge, distills a 98M student reward, and repeatedly refreshes the student on new rollouts. Its RL target is the robot video world model; the paper does not demonstrate downstream VLA-policy improvement.

Artifact caveats:

- World-Env has Apache-2.0 code and an official ModelScope checkpoint link.
- World-VLA-Loop's official repository still says source code is in preparation; no weights or SANS data release was verified.
- RoboAlign-R1's paper/project page claim code, models, and data, but the linked GitHub repository was only a placeholder during this audit and no reusable license was found.
